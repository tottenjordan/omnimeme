# Note: UI Interfaces - Guided Experience & Free-form Text Widget

## Overview
The application supports two user interfaces for video creation, both powered by the underlying ADK Video Directing Agent.

## Interfaces
1. **Guided Experience**:
   - Structured step-by-step form capturing key directing variables:
     - Subject & Scene Concept
     - Action & Motion Pace
     - Camera Framing & Movement
     - Lighting, Environment & Mood
     - Aesthetic Style & Lens Choice
     - Duration & Aspect Ratio
   - Compiles user selections into a structured prompt schema for the ADK Directing Agent to refine.

2. **Free-form Text Widget**:
   - Single natural language input box.
   - User inputs rough idea (e.g. "a cat wearing sunglasses riding a skateboard down a neon alley").
   - Directing agent analyzes intention, expands visual and technical directives using Omni Flash best practices, and returns enhanced video prompt.
